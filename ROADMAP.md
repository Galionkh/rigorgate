# Roadmap

SignalForge develops in public around evidence quality, reproducibility, and validation—not promises of guaranteed returns.

## 0.1 — Public foundation

- [x] Secret-free offline demo
- [x] Modular price, filing, macro, and financial providers
- [x] Market-regime and technical discovery stages
- [x] Fundamental, accounting, valuation, and risk gates
- [x] Data-quality reporting and shadow outcomes
- [x] Public CI, contribution rules, and security policy

## 0.2 — Reproducible data layer

- [ ] Versioned point-in-time snapshot schema
- [ ] Parquet and DuckDB export
- [ ] Redistributable provider contract fixtures
- [ ] Dataset manifests with checksums and observation timestamps
- [ ] Improved SEC taxonomy mapping tests

## 0.3 — Validation laboratory

- [ ] Purged walk-forward evaluation
- [ ] Regime- and sector-stratified outcomes
- [ ] Calibrated uncertainty intervals
- [ ] Transaction-cost and slippage assumptions
- [ ] Public benchmark definitions and bias checklist

## 0.4 — Research experience

- [ ] Accessible interactive dashboard
- [ ] Candidate evidence diff between runs
- [ ] Rejection funnel and provider health views
- [ ] Sector-specific underwriting templates
- [ ] Optional local language support

## Not on the roadmap

- Guaranteed-return claims
- Unattended order execution
- Hidden proprietary scoring presented as objective truth
- Performance marketing based on immature samples
